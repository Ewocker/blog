前陣子在看小說《靈境行者》，讀到了這麼一段話，讓我在深夜裡愣住了好一陣子：

> 從人治到法治，是人類文明最大的進步，也是最寶貴的財富。聖人會死，但秩序不會。我們永遠不可能做到絕對的正義和公平，法律的目的也不是維護正義，而是維護秩序，只有穩定的秩序，才能讓人類文明持續下去，元始，秩序才是對弱者最好的保護。
>
> — 傅青陽，《靈境行者》第343章〈徇私枉法〉（賣報小郎君）

秩序和正義，聽起來像是同一件事，但其實從來都不是。

---

## 秩序是地板，正義是天花板

正義是主觀的。你心中的正義，和我心中的正義，很可能長得完全不一樣——這件事在每次社群媒體上的公審中都能看得一清二楚。而秩序不一樣，秩序是可以被寫下來、被執行、被檢驗的東西。

也因為這樣，沒有秩序的正義，往往長得很可怕。私刑是一種正義，暴民政治也是一種正義，強者用拳頭定義的規則同樣可以自稱正義。所以我後來慢慢理解，秩序其實是地板，而正義是天花板——你得先有地板站著，才有資格去談天花板有多高。

普通人沒有資源去爭取「正義」，沒有律師、沒有話語權、也沒有能上得了新聞的臉。但穩定的秩序不需要你爭取，它自動地把你納入保護範圍裡。這大概就是「元始，秩序才是對弱者最好的保護」這句話真正想說的事。

---

## 但秩序也可能是壓迫的工具

當然，事情沒有這麼簡單。秩序本身也可以是不正義的——殖民法是秩序，種族隔離也是秩序，它們一樣穩定、一樣可執行，卻保護著錯的一方。「惡法亦法」和「惡法非法」的爭辯，人類已經吵了幾千年，到現在也沒有標準答案。

於是問題就變成了：當秩序保護的是既得利益者，普通人的保護到底在哪裡？我沒有答案，但我覺得承認這個矛盾，本身就已經比假裝秩序永遠是對的更誠實一點。

---

## 工程師的視角：我們每天都在寫「秩序」

寫程式寫久了之後，我對這句話反而有種意料之外的共鳴。

Code is law[1]——智能合約是這樣，平台規則是這樣，其實我們每天寫的 lint rules 也是這樣。團隊裡的 code convention 從來就不是為了美觀，而是為了秩序。你可以覺得某個 tab 應該是兩格而不是四格（這才是**_正義_**），但團隊選擇了四格之後，重點已經不是誰的品味比較好，而是所有人能不能照著同一套規則走下去。

`convention > creativity`，這句話某種程度上就是秩序戰勝正義的縮影。而我自己也曾經在 code review 裡因為堅持「我覺得這樣寫比較優雅」而卡住整個 PR，後來才意識到，我在爭的其實是正義，但團隊需要的是秩序。

---

## 結語

我還沒有想清楚，什麼時候該為了正義去打破現有的秩序，什麼時候又該先守住秩序，再慢慢把正義往上疊。但我知道的是，每次我在深夜裡看到一句讓自己愣住的話，通常代表它戳到了一直沒被整理過的地方。

你呢？有沒有哪一次，是秩序保護了你，而正義根本沒有出現？
